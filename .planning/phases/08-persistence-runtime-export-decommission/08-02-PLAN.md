     - Verify fullDestPath starts with fullTargetDir + Path.DirectorySeparatorChar; throw InvalidDataException if false.
     - Return fullDestPath.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File System -> KfxPackage | Untrusted .kfx ZIP files crossing from disk or network into extractor |
| ZIP Archive Entry Names -> Local Paths | Relative path strings inside ZIP entries mapping to filesystem extraction paths |
| JSON Content -> Deserializer | Untrusted JSON text crossing into runtime payload parser |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-04 | Tampering / Elevation of Privilege | KfxSecurityValidator.cs | high | mitigate | Zip-slip defense: reject entry names containing `..` or leading `/` or `\` and verify canonical paths start with target directory. |
| T-08-05 | Denial of Service | KfxSecurityValidator.cs | high | mitigate | Decompression bomb defense: accumulate uncompressed byte size across entries and abort with InvalidDataException if exceeding 250MB. |
| T-08-06 | Information Disclosure | KfxPackage.cs | low | mitigate | Dual-payload separation: runtime payload strips editor undo history, selection arrays, and confidential workspace configurations. |
| T-08-07 | Denial of Service | KerfPlayer.cs | medium | mitigate | Validate numeric input parameters; guard against double.IsNaN and double.IsInfinity during matrix composition and time stepping. |
| T-08-SC | Tampering | BCL Assemblies | high | mitigate | Use only native .NET 4.5+ BCL assemblies (System.IO.Compression, System.IO.Compression.FileSystem) with zero external NuGet packages. |
</threat_model>
