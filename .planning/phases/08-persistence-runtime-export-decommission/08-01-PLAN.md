## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File System -> StorageManager | Untrusted or malformed .kerf JSON project files crossing into deserializer |
| Legacy Hash -> Model GUID | Untrusted 32-bit hash integers mapping to layer objects |
| Document Model -> Evaluator | Missing or deleted layer references causing potential null dereferences |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Tampering | DocumentMigrations.cs | medium | mitigate | Validate JSON schema; wrap deserialization in try/catch with safe fallback to empty document and warning logging in MigrationReport. |
| T-08-02 | Denial of Service | AnimationTypes.cs / StateMachineRuntime.cs | high | mitigate | Guard evaluation loops with `if (!item.IsActive) continue;` to prevent NullReferenceException on deleted layer targets. |
| T-08-03 | Elevation of Privilege | PropertyBinder.cs | low | accept | FNV-1a hash mapping operates strictly in-memory on local layer IDs with no OS or shell execution capabilities. |
| T-08-SC | Tampering | BCL Assemblies | high | mitigate | Use only native .NET 4.5+ BCL assemblies (System.Web.Extensions, System.IO.Compression) with zero external NuGet packages. |
</threat_model>
