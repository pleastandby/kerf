  <action>
    Per D-01 and D-02 in CONTEXT.md:
    1. Define `RenderTransform` class in `CanonicalDocument.cs`:
       - `TranslationX`, `TranslationY` (default 0.0)
       - `ScaleX`, `ScaleY` (default 1.0)
       - `Rotation` (degrees, default 0.0)
       - `SkewX`, `SkewY` (degrees, default 0.0)
       - `OriginX`, `OriginY` (normalized anchor point, default 0.5, 0.5 for center pivot)
       - `IsIdentity` property returning true if all fields are at default values.
       - `Reset()` method restoring defaults.
       - `Clone()` method creating a deep copy.
       - `ToMatrix(double width, double height)` method computing the 3x3 / 2D affine transform matrix relative to the layer's pivot:
         `Pivot = (OriginX * width, OriginY * height)`
         $M = \text{Translate}(T_x + \text{Pivot}_x, T_y + \text{Pivot}_y) \times \text{Rotate}(\theta) \times \text{Scale}(S_x, S_y) \times \text{Skew}(K_x, K_y) \times \text{Translate}(-\text{Pivot}_x, -\text{Pivot}_y)$.
    2. Add `RenderTransform RenderTransform { get; set; }` property to `LayerNode`.
    3. Ensure `LayerNode.Clone()` and serialization support `RenderTransform` cleanly.
  </action>
